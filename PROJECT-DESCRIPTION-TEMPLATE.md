# Alien space station

40/2021 - Veljko J

Fly around in an UFO near Earth with your smaller UFO crew and play with the lighting.

## Controls

Camera speed is modified to be faster if you enter the UFO by pressing ENTER:

W,S,A,D,UP,DOWN -> CAMERA_POSITION, CAMERA_SPEED_STANDARD (different standard in UFO), MODEL_POSITION (driving)

LEFT_SHIFT + {W,S,A,D,UP,DOWN} -> CAMERA_POSITION, CAMERA_SPEED_INCREASED (different increase in UFO), MODEL_POSITION (
driving)

UFO moves towards where you are looking when entered. You exit the UFO by pressing ENTER again.
If you want to reset the UFO back to the platform including yourself press SPACE.

MOVING THE MOUSE -> CAMERA_ROTATION

SCROLLING -> CAMERA_ZOOM

P -> LIGHTS_TOGGLE_POINT

I -> LIGHTS_TOGGLE_DIR

O -> LIGHTS_TOGGLE_SPOTLIGHT

N -> MODEL_TOGGLE_NORMALS

F2 -> GUI_TOGGLE

If you don't do anything for 10 seconds NOTHING will happen.
Detects unsupported keys with NOTHING also.
